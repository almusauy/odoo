## ١) الأدوار: نظام نوبل عنده **١٠ أدوار و٧٢ علم صلاحية**

### الموجود بأودو قياسياً (تفعيل/إسناد فقط) ✅

| دور نوبل | مقابله بأودو | الحالة |
|---|---|---|
| مدير عام (٥ أشخاص، is_gm يتجاوز كل شيء) | مدير بكل التطبيقات + مدير مصاريف (إعفاء الموافقة الذاتية) | ✅ مبني ومختبَر |
| محاسب (مصطفى — كل الفروع، **بلا كلف/أرباح**) | كامل ميزات المحاسبة | ✅ مبني — ⚠️ الحجب المالي تخصيص |
| محاسب خارجي (**قراءة فقط**، يشوف الضريبة) | مجموعة «تدقيق للقراءة فقط» بالمحاسبة (group_account_readonly) | ✅ موجودة قياسياً — تُسند عند الحاجة |
| موظف مبيعات / كاشير | بائع + فوترة | ✅ مبني |
| مندوب مبيعات (نطاقه **«سجلاته»**) | بائع «مستنداته الخاصة فقط» — نفس الفكرة قياسياً | ✅ المجموعة موجودة |
| أمين مخزن / مجهز | مستخدم مخزون | ✅ مبني |
| مسؤول مشتريات محلية | مستخدم مشتريات (+ رؤية الكلفة) | ✅ المجموعة موجودة |
| مدقق جرد | مستخدم مخزون (الجرد ضمنه) | ✅ |
| مدير فرع | مدير مبيعات **مقيّد بفرعه** | ⚠️ التقييد بالفرع تخصيص |

### يحتاج تطويراً (أهم فجوات الصلاحيات) 🔧

| ميزة نوبل | التفصيل | بأودو |
|---|---|---|
| **أعلام الحجب المالي** | view_cost · view_profit · view_valuation · view_mfg_cost · حجب أسماء الموردين (كنية بدل الاسم) | 🔧 أكبر فجوة — قواعد حقول وسجلات مخصصة |

| **منح فردية بمدة انتهاء** | user_perm_overrides: منح/سحب لشخص بتاريخ نفاد (بيع على الواصل · من مخزن ثانٍ · قراءة الأستاذ) | 🔧 غير قياسي |
| سقف خصم رقمي متدرج | حالياً طبّقنا صفر/الكل (مطابق لواقعه: ٠٪ للبيّاعة، ١٠٠٪ للمدير) — التدرج الرقمي لو احتاجه | 🔧 |
| موافقات بعتبات مبالغ | نظامه: بلا موافقة <٥٠ ألف · مدير حتى ٥٠٠ ألف | 🔧 (مرحلتا الشراء مفعّلتان بلا عتبة) |
| «ما توافق على طلبك» بكل المسارات | طبقناها بالمصاريف قياسياً؛ بنظامه تشمل ١٢ مساراً (رواتب · سلف · تقفيلة · مرتجع…) | ⚙️/🔧 تدريجياً مع كل مسار |

## ٢) بطاقة الصنف: نوبل ↔ أودو

| حقل نوبل | بأودو | الحالة |
|---|---|---|
| رئيسي + فرعيات (سماكة/لون/أبعاد) | القالب الأم + المتغيرات | ✅ مفعَّل ومختبَر |
| vsku لكل فرعي | رمز مرجعي لكل متغير | ✅ |
| وحدات متعددة بمعامل (ربطة=١٠ · م³=٤٨) | «العبوات» بأودو ١٩ = وحدات إضافية على البطاقة | ✅ مختبَر مع الأرضية |
| **باركود لكل وحدة قياس** | أودو ١٩: باركود على الصنف فقط | 🔧 فجوة |
| سعر خاص لكل وحدة (سعر جملة للربطة) | قوائم الأسعار (قواعد بالكمية) | ⚙️ تنضبط مع أسعار الفئات |
| **٥ أسماء بحث** (رئيسي·سوق·قديم·إنكليزي·كنية) | اسم واحد + رمز + باركود | 🔧 فجوة بحث — نقترح علامات تصنيف أو حقل كنية |
| أرضية السعر (نسبة+مبلغ) | ✅ بنيناها اليوم | ✅ |
| هامش مستهدف + سقف شراء (مدير فقط) | 🔧 لاحقاً | |
| حد إعادة الطلب | قواعد إعادة التوريد | ✅ قياسي |
| مهلة توريد للصنف/المورد | آجال التوريد على سطر المورد | ✅ قياسي |
| ربطة كصنف مستقل تنفك تلقائياً | يحتاج تصنيع (BoM) أو نبقيها وحدة | ⏳ قرار مع قسم التقطيع |
