# ١٧ — جرد التطبيقات: المنصَّب · المفعَّل · الناقص

**التاريخ:** ٢٠٢٦-٠٩-٠١ · بطلب المالك: *«نزلنا التطبيقات اللي نحتاجها وفعّل
لنا إياها وشوف لنا شنو ناقص بيهن — خلي نبلش تطبيق تطبيق»*

الرموز: ✅ جاهز ومتحقَّق · ⚙️ جاهز بأودو يبقى إعداده · 🔧 يحتاج تطوير · 🏢 متوفر على أودو.sh إنتربرايز فقط · ⏳ ينتظر جواب/قرار

## التطبيقات المنصَّبة (١٣)

المبيعات · المشتريات · المخزون · الفوترة (بالقالب العراقي) · الموظفون ·
المصاريف · جهات الاتصال · كلف الاستيراد · التوصيل · هامش المبيعات (+من
الكلفة الفعلية) · العراق-المحاسبة

## ١) المبيعات

| البند | الحالة |
|---|---|
| أوامر بيع · فوترة · خصم على السطر · قوائم أسعار (جملة/مفرد) · هامش ربح · حد ائتمان | ✅ |
| فئات أسعار بحد كمية أدنى (مثل نظامك) | ⚙️ قوائم الأسعار تدعمها — تنملى بعد جواب أسئلة التسعير الأربعة |
| أرضية السعر (الكلفة + ١٠٪) وحارس يرفض البيع تحتها | 🔧 تطوير صغير (أودو يحذّر بس ما يمنع) |
| سقف خصم لكل بائع + موافقة المدير عند التجاوز | 🔧 |
| ٣ نسخ طباعة (زبون · سائق · مجهز) بدون أسعار للمجهز | 🔧 قوالب طباعة |
| عربون + تثبيت سعر + مدة حجز (فعّلتها بنظامك ٠٨-٢٥) | ⚙️ العربون قياسي · تثبيت السعر والمدة 🔧 |
| عروض وباقات (SAL-09 ستايل طلبات) | ⏳ بعد جواب التسعير |
| حجب طبقة الشركات عن البائع (DEC-12) | 🔧 قواعد عرض |
| مندوب من قائمة الموظفين بلا دخول | ⚙️ بنية HR جاهزة — يبقى ربطه بأمر البيع 🔧 |

## ٤) المحاسبة والفوترة

| البند | الحالة |

| طلب مصروف: موظف يقدّم ← المدير يوافق ← المحاسب يرحّل ويقدر يعدّل | ✅ قياسي بتطبيق المصاريف |

## ٦) حالة سؤال «الشركات خلصتها لو لا؟»

**المنجز والمثبَت بالاختبارات:** الشركات الثلاث بخصائصها · دليل واحد
مشترك بحسابات التبادل · العزل التام (قيود جبل ما تبين بغابات ونوبل —
اختبار آلي يثبتها كل بناء) · الدورة الكاملة شراء→بيع→تحصيل→إقفال ناجحة.

**الباقي:** أتمتة التوليد المتبادل للفواتير بين الشركات (🏢 فوق) +
تسوية جاري الشركات دورياً (نصمّمها سوية بعد أول شهر تشغيل تجريبي).
