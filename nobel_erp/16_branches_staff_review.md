# ١٦ — ورقة مراجعة: الفروع · المخازن · الموظفون (مستخرجة من نظام نوبل)

**التاريخ:** ٢٠٢٦-٠٩-٠١ · **الحالة:** ✅ **صادق المالك بنفس اليوم** («نعم اعتمد ٥ فروع و٧ مخازن») — **وانبنت**: ١٥ صندوق فرع + ٣ صناديق دولار + ٢١ مخزن، مع اختبار يثبتها
> المالك: *«أسماء الفروع اخذها من نوبل… والموظفين كذلك والمستخدمين… بس راجع وياي»*
> هذا الملف يحلّ محل صفَّي «ما أعرف أسماء الفروع/المخازن» بالملف ١٤.

---

## ١) الفروع — **٥ مو ٤**

المصدر: `sql/386` (خط الأساس المقيس بعد التنفيذ) بنظام نوبل:

| # | الفرع | صندوقه بنظام نوبل |
|---|---|---|
| ١ | شارع الهادي | 181-1 |
| ٢ | الصالحية | 181-2 |
| ٣ | حي تونس ١ | 181-3 |
| ٤ | حي تونس ٢ | 181-4 |
| ٥ | الداخلية | 181-6 |
| — | صندوق الدولار (مو فرع) | 181-5 |

⚠️ **ملاحظة للمصادقة:** المالك قال سابقاً «٤ فروع»، لكن **بقراره ٢٠٢٦-٠٨-٢٧**
(«نعم الداخلية يسويها فرع» — `sql/386`) صارت **خمسة**. نعتمد الخمسة؟

**الأثر بأودو:** يوميّات الصندوق = ٥ فروع × ٣ شركات = **١٥ يوميّة دينار**
+ صندوق دولار لكل شركة (٣) — بدل حسبة الـ١٢ القديمة بـDEC-20.

## ٣) الموظفون — ١٦ مستخدماً (المصدر: `docs/ROSTER.md` بنظام نوبل، بقائمة المالك نفسها)

| المجموعة | العدد | الأسماء |
|---|---|---|
| مدراء عامون (إعفاء موافقات) | ٥ | فاضل · إبراهيم · محمد · علي (سجاد) · ياسر |
| محاسب الشركة (كل الفروع، **بلا كُلف وأرباح**) | ١ | مصطفى عماد |
| محاسب فرع + كاشير | ١ | عبد العزيز عيدان |
| بائع + كاشير (± محاسب فرعه) | ٥ | علاء ثامر (الداخلية) · علي رباط (الصالحية) · قصي (الصالحية) · علي سليم (شارع الهادي) · محمد حسن (حي تونس ١) |
| بائع + مندوب + كاشير | ١ | يوسف حسين (حي تونس ٢) |
| مندوب + أمين مخزن | ٢ | رضوان (حي تونس ١) · أيمن (حي تونس ٢) |
| أمين مخزن | ١ | مصطفى فاضل (عويريج ± حي تونس ١) |

**أسئلة الحسم قبل فتح الحسابات بأودو** (معلَّقة من قبل بنظام نوبل نفسه — `sql/386`):
1. عبد العزيز محاسب فرعَي حي تونس ١ **و**٢ — بأودو نقدر نعطيه الفرعين. نعم؟
2. مصطفى فاضل: عويريج وحده لو ويّاه حي تونس ١؟
3. الحسينية بلا أمين مخزن — منو نعيّن؟
4. رموز الدخول: تنكتب يدوياً وقت الفتح وتتغير بأول دخول (ما تنحفظ بأي ملف).

## ٤) التسعير — اللي لگيته بنظامك (N-03 ينحل تقريباً)

نظام نوبل عنده نموذج تسعير كامل شغّال:

| الآلية | التفصيل بنظامك | مقابلها بأودو |
|---|---|---|
| فئات زبائن | جملة · مفرد (`product_tier_prices` مع حد كمية أدنى) | قوائم الأسعار (مفعَّلة ✅) |
| أرضية السعر | الكلفة + ١٠٪ أو «أقل سعر بيع» يدوي — البيع تحتها **مرفوض** | هامش + حارس (يحتاج تطوير بسيط للحارس) |
| سقف خصم لكل بائع | «الخصم يتجاوز صلاحيتك (أقصاها ٠٪)» | خصم على السطر (مفعَّل ✅) + صلاحيات |
| عربون + تثبيت سعر + مدة حجز | فعّلها المالك ٢٠٢٦-٠٨-٢٥ (`sql/338`) | عربون Down payment (جاهز) + تثبيت السعر (تطوير) |

**الأسئلة الأربعة الباقية للمالك:** بالملخص النهائي أدناه.
