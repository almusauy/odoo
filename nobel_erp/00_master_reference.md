# القسم ٤: القرارات المحاسبية المعلّقة (11 بوابة — تحتاج توقيع المحاسب)

هاي **موقوفة على محاسبي** — لا تكمّل المحاسبة بين الشركات قبل جوابه:

1. هل **Company C** (الشركة التجارية) تمسك دفتراً قانونياً مستقلاً، لو طبقة تجارية فقط؟
2. عدد المستودعات ونموذج الملكية (8 مشتركة لو 8 لكل شركة)؟
3. قيود المصروفات بين الشركات + الحسابات المتقابلة + الضريبة؟
4. نسبة الهامش بين الشركات + أكواد الحسابات + المعالجة القانونية؟
5. تسلسل الموافقات لكل عملية حساسة (هدايا، حد أدنى، تجاوز ائتمان، مرتجعات)؟
6. أساس عمولة السائق (ثابت/حسب النوع/الزبون)؟
7. سياسة التكلفة الواصلة: تقديرية إدارية لو قيد GL فعلي؟
8. مصدر سعر الصرف + من يخوّل التجاوز + حسابات الربح/الخسارة؟
9. قواعد الرواتب والاستقطاعات + تفاصيل ربط جهاز ZKTeco؟
10. حساب واتساب للأعمال + القوالب المعتمدة + موافقة الزبون؟
11. أي مستندات تحمل شعار Company C بينما البائع القانوني A/B (يحتاج موافقة قانونية)؟

**النظام المحاسبي العراقي الموحّد** — أهم 3 أسئلة للمحاسب:

# القسم ٧: ربط Claude Code بأودو — 3 خطوات

**الخطوة ١: نصّب موديول MCP داخل أودو**
- من أودو: **Apps** → ابحث **MCP Server** → نصّبه
- أعطِ مستخدمك الصلاحية: Settings → Users → افتح مستخدمك → تبويب Other → MCP Server access = **MCP Administrator** → احفظ وحدّث الصفحة (Ctrl+Shift+R لو ما ظهرت القائمة)

**الخطوة ٢: فعّل السيرفر وانسخ الرابط**
- السيرفر يجي **معطّل** (أحمر) — اضغطه فيصير **Enabled** (أخضر)
- افتح تبويب **«Connect to Claude»** وانسخ الرابط — **مفتاحك مدمج داخله**
- اختر النماذج المسموحة (مبيعات/مخزون/محاسبة) وفعّل قراءة/كتابة/إنشاء/حذف حسب الحاجة

**الخطوة ٣: اربط Claude Code (أمر واحد)**
```
claude mcp add --transport http odoo https://<اسم-أودو-مالك>/mcp \
  --header "Authorization: Bearer <المفتاح-مالك>"
```
- Claude Code يكتشف كل أدوات أودو تلقائياً عند الاتصال

**🛡️ الأمان:** ابدأ بصلاحية **قراءة فقط** — تفحّص كل شي، وبعدها فعّل الكتابة تدريجياً. كل مفتاح يشتغل كمستخدم أودو محدّد (تنطبق صلاحياته)، والمفاتيح مشفّرة SHA-256.
